# APIF — AI Propaganda Intelligence Framework
#
#   pip install -r requirements.txt
#
# This is the complete dependency set. There is no second requirements file and
# no step outside pip: no system ffmpeg, no --system-site-packages venv, no
# pre-downloaded Hugging Face cache.
#
# torch, transformers and librosa used to be required and are deliberately gone.
# They existed for one thing, a local whisper-small, and cost ~2GB of wheels plus
# a 10-20s load on the first request. Transcription is now an API call and the
# video model runs on onnxruntime, so nothing left in the tree imports torch.

# --- web service ---
fastapi
uvicorn[standard]
pydantic
pydantic-settings
python-multipart
httpx

# --- LLM enrichment ---
anthropic

# --- video deepfake: local ONNX EfficientNet-B0 ---
# The graph is apif/data/models/ffpp_efficientnet_b0.onnx. headless, not plain
# opencv-python: a server has no display, and the GUI build drags in GTK/X11
# shared objects that add weight and break slim base images.
onnxruntime
opencv-python-headless

# --- media handling ---
# Ships a static ffmpeg binary in the wheel, so audio extraction and transcoding
# work on a bare container with nothing installed at the OS level. It does not
# ship ffprobe; detectors/media.py reads duration from ffmpeg's own output.
imageio-ffmpeg

# --- market correlation ---
yfinance
pandas
numpy

# --- coordination graph ---
networkx
scikit-learn

# --- storage + source authentication ---
SQLAlchemy
pypdf
python-Levenshtein
