Color palette

Background (main/light sections):
#f6ede4 — warm cream/off-white, not pure white
Primary text/headings:
#0b1530 — deep navy, almost black
Accent/brand color:
#e6500f — burnt orange (used for CTAs, italic emphasis words, icons, small eyebrow labels)
Secondary dark sections:
#0b1530 (same navy) used as a full-bleed background with white text for contrast blocks
Body copy: a muted navy/gray (roughly 60-70% opacity of the navy) for paragraph text, keeping it softer than headings

Typography

Headings use Inter (sans-serif, weight ~500), quite large (50-55px for H1/H2), often mixing a bold sans headline with an italicized serif-style accent word for emphasis (e.g. an italic phrase in orange right under a bold headline)
Small eyebrow labels above headings are in an italic serif font, orange, uppercase-adjacent style, giving a "tag" feel
Body paragraphs use a serif font at readable size with generous line-height
Monospace/technical font used inside dark UI-mockup graphics (labels like "// KILL CHAIN", "SCOPE - BLACK BOX") to evoke a terminal/security aesthetic

Layout & UX patterns

Sticky top nav: logo left, horizontal menu center, "Sign in" (ghost button) + primary CTA (outlined/filled button) right
Hero section: two-column layout — left is headline + subtext + CTA button, right is a dark "tech visualization" card (navy background, node/graph diagram with orange highlight on the active step) — this recurs throughout the page as a visual motif for illustrating processes/pipelines
Alternating section backgrounds: cream → dark navy → cream, creating rhythm and visual breaks between content blocks
Logo/trust bar: grayscale partner/client logos in a row under the hero
Accreditation/badges row with icon + label + small caption (e.g. certification badges)
Numbered card carousel (01/02/03) with up/down arrow controls, paired with a live diagram on the right that updates per selection
Process/methodology section uses a horizontal flow diagram with pill-shaped nodes connected by arrows and dashed lines, color-coded by phase (orange for active/looping phases, outline for linear phases)
Buttons: solid orange rounded (8px radius) for primary actions, outline/ghost navy for secondary actions
Floating chat widget button (bottom-right, orange circle) persists across scroll

Overall vibe: a "cybersecurity meets editorial" aesthetic — warm neutral background instead of stark white/black, serif+sans font pairing for a more premium/human feel, dark terminal-style graphics to signal technical credibility, and a single confident accent color (orange) used sparingly for emphasis and CTAs.

For PhishermanAI (a phishing-related product, I'd guess simulation/detection), this system would translate well — you could keep the same warm cream + navy + orange palette (or swap orange for a different accent tied to your brand), reuse the dark terminal-graphic motif for showing attack chains/email flow visualizations, and keep the alternating light/dark section rhythm.
